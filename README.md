# 알고랩 — 중학교 정보 학습 사이트

2022 개정 중학교 정보 ‘알고리즘과 프로그래밍’ 영역의 성취기준 9개를 바탕으로 만든 정적 학습 웹사이트입니다.

## 바로 열기

`index.html`을 Chrome 또는 Edge에서 여세요. 설치나 로그인이 필요하지 않습니다. CSS와 JavaScript 파일은 같은 폴더에 두세요.

로컬 서버로 열려면 Node.js 설치 환경에서 `node serve.cjs`를 실행한 뒤 표시된 주소를 여세요.

## 포함된 내용

- 9개 학습: 개념, 예시, 3단계 활동, 피드백이 있는 확인 문제, 학습 메모
- 4개 코딩 미션: 코드 편집, 독립 Worker 실행, 테스트, 예시 풀이, 코드 다운로드
- 순차·이진 탐색 비교 및 예시 코드의 단계별 디버거
- 협력 프로젝트 활동지, 자기 점검, 텍스트 다운로드 및 인쇄
- 검색, 영역·완료 필터, 브라우저 로컬 학습 기록
- 성취수준 안내 및 출처

성취기준은 교육과정 MCP와 대조했습니다. 성취수준 방향은 『2022 개정 교육과정에 따른 중학교 정보과 성취수준』의 알고리즘과 프로그래밍 영역을 참고했습니다. 상세 출처는 사이트의 ‘성취수준 안내’에 있습니다. 체크 포인트와 활동은 학습용으로 재구성했으며 공식 A~E 평정을 자동으로 내리지 않습니다.

## 개인정보 및 실행

외부 서비스·CDN·분석 도구를 사용하지 않습니다. 메모, 코드, 체크 상태는 `localStorage`의 `algolab-v1`에 저장됩니다. 중요한 기록은 내려받아 보관하세요. 코드 실행은 별도 Web Worker에서 수행하며 2초 후 중단합니다. 교육용 실행기이며 임의의 신뢰할 수 없는 코드를 안전하게 분석하는 보안 샌드박스는 아닙니다.

## 향후 GitHub Pages 배포

사용자가 GitHub 연결을 마친 뒤 공개 저장소에 이 폴더의 파일을 올리고, Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면 됩니다. 상대 경로만 사용하여 프로젝트 Pages 하위 경로에서도 동작합니다. 현재는 로컬 제작본입니다.
